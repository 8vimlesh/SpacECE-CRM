1. Executive Summary

The Spacece WhatsApp Communication & Tracking System is an enterprise CRM platform engineered for Spacece India Foundation. It combines unified parent WhatsApp messaging, Kanban pipeline lead tracking, CSV bulk contact imports, Meta template management, audience-targeted broadcast campaigns, centralized document storage, real-time analytics, quota tracking, and a reactive Automation Engine for n8n webhooks.

2. System Architecture & Database Reference

All database tables persist locally in browser IndexedDB named SpaceceIndiaFoundationCRM using Dexie.js:

Table Name Entity Description Key Fields & Data Attributes
contacts Parent Contacts Directory id, name, phone, linkedStudentClass, tags, optedOut, status, createdAt
inquiries Admission Leads Pipeline id, contactId, pipelineStage, followUpDate, notes
messages WhatsApp Message Logs id, contactId, direction, type, content, status, timestamp
templates WhatsApp Message Formats id, name, category, status, messageBody
campaigns Broadcast Announcements id, name, templateId, audienceType, status, sentCount, createdAt
media Educational Files Storage id, fileName, fileType, fileUrl, uploadDate, size
whatsAppSettings Meta API Credentials id, displayName, phoneNumber, phoneNumberId, wabaId, accessToken, connectionStatus
subscription Quotas & Billing Invoices id, planName, contactLimit, messageLimit, paymentHistory, status, renewalDate
automationRules Reactive Event Rules id, name, description, triggerEvent, conditions, actions, status, executionCount
automationLogs Audit Logs Table id, timestamp, ruleId, ruleName, type, recipient, status, notes

5. How to Test Every Module

  1. Open http://localhost:5173/ in your browser.
  2. Settings: Verify WhatsApp credentials and test Access Token password masking.
  3. Chats Inbox: Send a reply to a parent and test the Test Incoming Message simulation tool.
  4. Inquiry Board: Drag a lead card across pipeline stages (New Inquiry → Contacted → Interested → Admitted).
  5. Contacts & CSV Import: Add a duplicate phone number to test duplicate prevention; test CSV bulk import file.
  6. Templates & Campaigns: Create a template, set status to Approved, and run a 3-step broadcast campaign.
  7. Media Library: Upload an image or PDF document and click Preview to open the full-screen viewer modal.
  8. Analytics & Reports: View the 7-day SVG message trend chart and click Export Report (CSV).
  9. Subscription / Usage: Inspect live contact import capacity and monthly message quota progress bars.
  10. Automation Engine: Toggle a rule status pill to ACTIVE, create a new inquiry, and verify the automated execution log in Automation Audit Logs.
